# النموذج الأولي لموقع د. محمد عبدالله الجرباني
### استشاري جراحة المخ والأعصاب والعمود الفقري

نموذج أولي حديث وتفاعلي لموقع طبي متخصص، مبني باستخدام **React 18** و **Vite** و **Tailwind CSS** مع دعم كامل للغة العربية واتجاه اليمين إلى اليسار (RTL).

---

## 🌟 ميزات النموذج الأولي

1. **تصميم طبي راقٍ وموثوق:**
   - نظام لوني طبي احترافي: الأزرق الطبي الداكن (`#1B4965`) كلون أساسي، التركوازي/السماوي (`#5FA8D3`) كلون ثانوي، والذهبي الدافئ (`#D4A843`) لإضفاء الفخامة.
   - خطوط عربية واضحة ومميزة (Cairo & Tajawal).
   - تجاوب كامل مع كافة أحجام الشاشات (Mobile First).

2. **بيانات طبية حقيقية 100%:**
   - **الاسم:** د. محمد عبدالله الجرباني
   - **التخصص:** استشاري جراحة المخ والأعصاب والعمود الفقري
   - **رقم الحجز المباشر:** `784545908`
   - **المواقع المعتمدة:**
     - صنعاء: شارع تعز – جولة 45 – فوق صيدلية الفيصل، أمام مطاعم الخطيب
     - صنعاء: البيت الطبي – شارع الزبيري، بجانب المستشفى الجمهوري، برج الأطباء، الدور الرابع
     - صنعاء: مركز ابن سيناء الطبي التشخيصي
     - الحديدة: عيادة شارع صنعاء

3. **هيكل الصفحات السبع (7 صفحات رئيسية + صفحة المقال الفردي):**
   - **الرئيسية (`/`):** Hero section متكامل مع تدرجات لونية، زر الحجز، إطار صورة الطبيب، مميزات العيادة، 6 تخصصات رئيسية، إحصائيات، أحدث المقالات، وقسم CTA.
   - **عن الطبيب (`/about`):** السيرة المهنية، المؤهلات والاعتمادات، الرؤية والرسالة، وقيم الممارسة الطبية، مع إطار مخصص لصورة الطبيب.
   - **التخصصات الطبية (`/specializations`):** عرض مفصل لكافة الـ 13 تخصصاً طبياً مع شريط بحث وتصفية وتفاصيل التدخلات الجراحية.
   - **الخدمات الطبية (`/services`):** أقسام مستقلة لكل خدمة جراحية مع بطاقات الميزات وإرشادات الطبيب للمرضى.
   - **المقالات الطبية (`/articles`):** مكتبة مقالات توعوية (الانزلاق الغضروفي، أورام الدماغ، آلام الظهر، الصرع) مع نظام بحث وتصفية.
   - **المقال الفردي (`/articles/:id`):** تصميم قراءة نظيف مع شريط تقدم ومربعات اقتباس وسيرة كاتب المقال ومقالات ذات صلة.
   - **العيادات والمواقع (`/locations`):** بطاقات لجميع مواقع صنعاء والحديدة مع العناوين التفصيلية وأوقات العمل ومحاكاة خريطة تفاعلية وأزرار الاتصال.
   - **تواصل معنا (`/contact`):** نموذج حجز ذكي، أزرار الاتصال الهاتفي والواتساب المباشر، وتفاصيل الفروع.

4. **مكونات عامة تفاعلية:**
   - شريط علوي ذكي يثبت عند التمرير (Sticky Header) مع قائمة جانبية متحركة للجوال.
   - زر واتساب عائم سريع للحجز.
   - زر العودة لأعلى الصفحة (Scroll to top) يظهر تلقائياً.
   - تذييل صفحة غني بـ 4 أعمدة ومعلومات الاتصال وحقوق الملكية.
   - علامات واضحة للمعلومات التي تحتاج تأكيد الطبيب (`* يحتاج تأكيد من الطبيب`).

## 🚀 طريقة التشغيل والتشغيل التجريبي

### 1. تثبيت الحزم (Dependencies):
```bash
npm install
```

### 2. تشغيل السيرفر المحلي للتطوير:
```bash
npm run dev
```
سيفتح الموقع على الرابط المحلي: `http://localhost:3000`

### 3. بناء المشروع للإنتاج:
```bash
npm run build
```

## 📌 ملاحظات التسليم للعرض على العميل:
- تم استخدام Placeholders أنيقة وواضحة لصورة الطبيب وللخرائط التفاعلية بدون الاعتماد على أي روابط صور خارجية قد تنكسر.
- تم تظليل أي أرقام تقريبية (مثل عدد العمليات وسنوات الخبرة والشهادات التفصيلية) بملاحظات صريحة تفيد بأنها بحاجة لتأكيد ومراجعة الطبيب.
- جميع النصوص والمسارات مكتوبة باللغة العربية الفصحى مع دعم كامل لخصائص RTL.
